# Gel Data (Gel / formerly EdgeDB)

> Gel is an open-source graph-relational database that supercharges PostgreSQL with a modern object-oriented data model, the EdgeQL query language (plus full SQL and GraphQL), a built-in migration and branching system, integrated authentication (OAuth, email/password, magic links, passkeys/WebAuthn), and GenAI features (automatic embeddings, RAG, vector search). Built by Gel Data Inc. (acquired by Vercel; managed Gel Cloud wound down), the database remains fully open source.
